Face-ID-Test

Prüft, ob dein Handy das Tresor-Passwort später mit Face ID entsperren kann. Es wird nichts an deinen Apps geändert.

Schritt 1: Face ID einrichten

Dein Handy legt einen Test-Passkey „Face-ID-Test“ an und fragt nach Face ID.

Schritt 2: Mit Face ID entsperren

Entsperrt mit Face ID einen geheimen Testtext. Klappt das, klappt es auch für den Tresor.
